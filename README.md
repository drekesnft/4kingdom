# Kingdom Wars

Mobile-first strategy game prototype built with React + Vite.

## MVP

- Vertical mobile interface
- Tile-based world map
- Drag/pan and zoom
- Selectable map tiles
- 3 resources: wood, iron, food
- 1 token: KING
- Initial terrain set: snow, forest, mountain, lake, golden crystal, rock deposit, dirt, farm, ruins and enemy camp

## Local development

```bash
git clone https://github.com/xploraantonio-lgtm/kingdom-Wars.git
cd kingdom-Wars
npm install
npm run dev
```

The first milestone is the interactive world map. Buildings, troops, territory ownership and multiplayer systems will be layered on top of this base.
